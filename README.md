# Muraqba Ads — Meta Ads, Zero to Hero

A free, self-paced, 10-module course that teaches Meta Ads (Facebook & Instagram
advertising) from absolute fundamentals through running professional campaigns —
rebuilt around Meta's 2025–26 **Andromeda** shift in how targeting actually works.

Shipped as a **single, self-contained HTML file**. No build step, no server, no
external dependencies at runtime — open it in a browser and it works.

---

## 1. Quick Start

1. Download `Muraqba Ads - Meta Ads Zero to Hero Course.html`.
2. Double-click it to open in any modern browser — **or** upload it to any static
   host (GitHub Pages, Netlify, Vercel, S3, cPanel, etc.) and rename it to
   `index.html`.
3. That's it. There is nothing to install and nothing to configure.

## 3. File Structure (Source)

The shipped file is **generated**, not hand-written. If you want to edit content
or styling, don't edit the big HTML file directly — edit the source and rebuild.
The source is a small Node.js project:

```
adscend/
├── content.js     # All course copy: brand name, modules, glossary
├── build.js       # Generator: HTML structure + CSS + JS + font embedding
└── index.html     # OUTPUT — generated by build.js, do not hand-edit
```

### Regenerating the site

```bash
node build.js
```

This reads `content.js`, embeds the three fonts as base64, injects the module
color gradient, and writes a fresh `index.html`.

## 5. How to Edit Colors / Branding

All color tokens live near the top of **`build.js`**:

```js
const META_BLUE       = '#0082FB';
const META_BLUE_DARK  = '#0064E0';
const META_CHARCOAL   = '#1C2B33';
const META_WHITE      = '#FFFFFF';
```

The 10 per-module accent colors are **not** hardcoded — they're generated
automatically by interpolating a gradient across these four values
(`moduleColor()` function), so changing the four base colors reflows the whole
site's palette consistently. No manual re-coloring of 10 modules needed.

The `:root { ... }` CSS variable block (also in `build.js`) maps these brand
colors to semantic roles (`--ink`, `--apricot` = primary CTA, `--pomegranate`
= warning accent, etc.) if you want to retarget specific UI elements.

## 6. Progress Tracking — How It Works

Completion state is stored client-side only, via `window.localStorage`, under
the key `muraqba_ads_done`. This means:

- Progress is **per browser**, not synced across devices.
- No backend, no accounts, no data collection — nothing leaves the visitor's browser.
- Clearing browser storage resets progress.

If you later want cross-device progress, that would require adding a real
backend (e.g. a small API + database) — out of scope for this static build.
